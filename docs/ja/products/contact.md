# Contact

お問い合わせの**受付・通知・自動返信**を管理します。自前フロントから公開 API に POST するか、`contact.luno.rest` でホスト公開できます。

## できること

- フィールド定義付きのお問い合わせフォーム
- 管理画面での受信一覧・ステータス
- **自動返信**（サンクスメール）
- Slack / Teams / Discord / Chatwork / LINE Notify などへの通知
- HubSpot / kintone 連携（設定による）
- **contact.luno.rest** でのホスト型ページ / iframe（Turnstile 対応）

## いつ使うか

- サイトのお問い合わせ・資料請求
- 通知をチャットや CRM に流したいとき
- フォーム UI を自前実装したくないとき（ホスト公開）
